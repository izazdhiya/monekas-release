# MONEKAS — unduhan aplikasi

Aplikasi kasir offline untuk Android (tablet & HP).

**Unduh versi terbaru:** buka [Releases](../../releases/latest), lalu pilih file sesuai aplikasi Anda:

| Aplikasi | File |
|---|---|
| MONEKAS | `MONEKAS-x.y.z.apk` |
| MONEKAS Bangunan | `MONEKAS-Bangunan-x.y.z.apk` |
| MONEKAS Resto | `MONEKAS-Resto-x.y.z.apk` |

File berakhiran `-arm64.apk` lebih kecil, untuk HP/tablet 64-bit modern. Jika ragu, pilih yang tanpa `-arm64`.

Setelah terpasang, MONEKAS memberi tahu sendiri jika ada versi baru (saat tersambung internet) — cukup tekan **Perbarui**.

Aplikasi membutuhkan Kode Aktivasi dari penjual.
